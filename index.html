你好，我是宋子骏，也叫紫色噩梦。我是中国科学院大学前沿交叉科学学院的博士生，研究工作同时在中国科学院自动化研究所展开。

我的研究关注 AI Agent，尤其是 Agent 强化学习、工具学习与后训练：当模型借助搜索、工具和外部执行系统把任务做得更好时，哪些能力可以留在模型里，并迁移到新的任务上。近期工作包括搜索 Agent 的细粒度信用分配、持续学习中的监督触发，以及端侧 Agent 的长程探索。

我也关注 AI for Science。我作为第一作者完成了 PertDiffBench，用于评测扩散模型在单细胞扰动响应预测中的适用范围。

本科毕业于大连理工大学软件学院。欢迎围绕研究方法、复现和开源项目来信交流。
